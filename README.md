# Final Sun

Public marketing and player-support pages for Final Sun on iPhone.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and click **Save**.

After GitHub finishes publishing:

- Marketing URL: https://japanlh-explore.github.io/FinalSun/
- Support URL: https://japanlh-explore.github.io/FinalSun/support.html

Open both links before adding them to App Store Connect.

## Files

- `index.html`: marketing page, including a Japanese introduction.
- `support.html`: player help and English/Japanese support instructions.
- `styles.css`: shared responsive styling.
- `.nojekyll`: serves the static files without Jekyll processing.

Support currently uses this repository's public GitHub Issues. Sign-in is required. No App Store download link has been added yet; add the public listing URL once available.
